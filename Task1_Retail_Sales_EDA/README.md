# OIBSIP Task 1: Exploratory Data Analysis on Retail Sales Data

Author: Brian Simpasa  
Internship: Oasis Infobyte (OIBSIP)  
Project: Task 1 – Exploratory Data Analysis (EDA)

## 1. Project Overview

This project applies Exploratory Data Analysis (EDA) techniques to a retail sales dataset to identify patterns in sales performance, customer demographics and product category performance.

The analysis uses Python to transform raw transaction records into meaningful insights that can support retail business decision-making.

## 2. Project Objectives

The main objectives are to:

- Inspect the dataset and assess its quality.
- Calculate descriptive statistics for numerical variables.
- Analyse monthly and quarterly sales trends.
- Examine customer age and gender distributions.
- Identify the best-performing product categories by quantity sold.
- Compare revenue generated by product category.
- Investigate relationships between numerical variables using correlation analysis.
- Develop additional visualisations to uncover useful business insights.
- Propose actionable business recommendations based on the findings.

## 3. Dataset Description

The dataset contains 1,000 transaction records and nine original variables:

| Variable | Description |
|---|---|
| Transaction ID | Unique transaction identifier |
| Date | Transaction date |
| Customer ID | Customer identifier |
| Gender | Customer gender |
| Age | Customer age |
| Product Category | Product category |
| Quantity | Number of units purchased |
| Price per Unit | Price of one unit |
| Total Amount | Total transaction value |

The dataset is stored in the `data` directory.

## 5. Methodology

The analysis follows these stages:

1. Data loading and initial inspection.
2. Data quality assessment, including missing values and duplicates.
3. Descriptive statistical analysis.
4. Date conversion and monthly and quarterly sales analysis.
5. Customer demographic analysis.
6. Product category quantity and revenue analysis.
7. Correlation analysis using a heatmap.
8. Additional analysis of average transaction value by age group.
9. Conclusion and business recommendations.

## 6. Key Findings

The analysis produced the following findings:

- The dataset contains 1,000 records with no missing values or duplicate records.
- May 2023 recorded the highest monthly sales of 53,150.
- The fourth quarter of 2023 recorded the highest quarterly sales of 126,190.
- Middle-aged Adults (45–59) represented the largest age group, accounting for 32.6% of transaction records.
- The gender distribution was relatively balanced, with female records accounting for 51%.
- Clothing recorded the highest quantity sold at 894 units.
- Electronics generated the highest revenue of 156,905.
- Price per Unit and Total Amount had a strong positive correlation of 0.85.
- Young Adults (18–29) recorded the highest average transaction value of 490.66.

## 7. Business Recommendations

Based on the findings, the project recommends:

1. Improve inventory planning around high-performing sales periods.
2. Develop targeted marketing strategies for different age groups.
3. Prioritise product categories based on both revenue and sales volume.
4. Investigate opportunities to increase average transaction value among senior customers.
5. Capture individual product identifiers and product costs to support more detailed product and profitability analysis.

## 10. Limitations

- The dataset contains product categories but no individual product names, so individual top-ten product rankings cannot be established.
- January 2024 contains only two transactions and is therefore an incomplete period for comparison.
- Product cost information is unavailable, preventing profitability analysis.
- The demographic analysis reflects transaction records; it should not automatically be interpreted as a count of unique customers.

## 11. Conclusion

This project demonstrates the application of Python-based exploratory data analysis to retail sales data. The findings highlight useful patterns in sales trends, customer demographics and product category performance.

The analysis provides a foundation for evidence-based retail decisions and demonstrates the value of data analytics in understanding business performance.
